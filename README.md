# AI Memory Tools Presentation

Claude Code, Codex CLI, Hermes Agent 사용자를 위한 AI 코딩 에이전트 메모리 도구 비교 리포트와 인터랙티브 HTML 프레젠테이션입니다.

## 바로 보기

- [인터랙티브 프레젠테이션](https://project820.github.io/ai-memory-tools-presentation/)
- [프레젠테이션 HTML 직접 링크](https://project820.github.io/ai-memory-tools-presentation/presentation.html)
- [원문 리포트](./ai-memory-tools-for-coding-agents.md)

## 포함된 파일

- `presentation.html`: 브라우저에서 바로 열 수 있는 10페이지 인터랙티브 발표 자료
- `index.html`: GitHub Pages 루트 주소를 발표 자료로 연결하는 리다이렉트 페이지
- `ai-memory-tools-for-coding-agents.md`: 발표의 원문 리포트
- `.gitignore`: 공유에 필요한 파일만 추적하기 위한 whitelist 규칙

## 발표의 목적

도구를 많이 나열하는 것보다, Claude Code, Codex CLI, Hermes Agent 각각의 사용 방식에 맞는 메모리 전략을 빠르게 고르는 데 초점을 둡니다.

핵심 질문은 다음과 같습니다.

- 어떤 도구가 내 에이전트 조합에 자연스러운가?
- 로컬 우선, self-hosted, managed cloud 중 무엇을 택할 것인가?
- 단순 회상과 reflection/consolidation 중 어디까지 필요한가?
- 여러 도구를 붙이기 전에 역할이 겹치지는 않는가?

## 디자인 및 공유 방식

프레젠테이션은 Wise 스타일의 색상 체계와 넓은 카드형 레이아웃을 참고했습니다. 한국어 가독성을 위해 Pretendard Variable을 HTML 내부에 포함해, 별도 폰트 파일 없이도 GitHub Pages와 로컬 브라우저에서 같은 타이포그래피로 표시되도록 했습니다.

## 검증 기준

원문 리포트에서는 다음 기준으로 도구 정보를 구분합니다.

- `직접`: 공식 문서 또는 GitHub README에서 확인한 내용
- `보조`: 검색 결과 또는 2차 자료 기반 내용
- `주의`: 벤더 주장 또는 독립 검증이 부족한 내용
